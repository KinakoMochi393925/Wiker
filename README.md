# Wiker Browser

Wiker Browser は、Webページ内の iframe を活用して構築された、HTML/CSS/JavaScript だけで動く「ブラウザ内ブラウザ」です。
実験的なプロジェクトであり、Webのセキュリティ仕様（X-Frame-Options）と向き合うために開発されました。

---

## 主な機能

- **スペース分割検索:** 入力されたワードをスペースで区切り、単語ごとのワンタップ検索ボタンを自動生成。
- **動画埋め込み最適化:** YouTube やニコニコ動画の通常のURL、またはニコニコの「sm番号」を直接入力することで、インライン再生（埋め込み用URL）へ自動変換して表示。
- **ランダムメッセージ:** ホーム画面を開くたびに、ちょっとしたメッセージでお出迎え。

---

## 【重要】一部のサイトが閲覧できない仕様について

現代の多くのウェブサイトは、セキュリティ（クリックジャッキング対策など）の観点から **`X-Frame-Options`** または **`Content-Security-Policy (CSP)`** という制限を設けています。これにより、外部サイトの iframe 内での表示がブロックされる仕様になっています。

### 閲覧可能なサイト（動作確認済み）
- **Wikipedia (モバイル版):** iframe 内での表示を許可してくれているため、非常に快適に閲覧できます。感謝！
- **YouTube / ニコニコ動画:** 通常の視聴ページはブロックされますが、本アプリが内部で自動的に**埋め込み専用URL（embed）に変換**するため、動画の視聴が可能です。
- **その他:** 青空文庫、Project Gutenberg、Weblio国語辞典 など。
- **検索エンジン**:開くことが可能だったExciteを使用しました。

### 閲覧できないサイト
- Google、Yahoo!、などの主要検索エンジンや、一般的なポータルサイト・ブログ。
- 大手サイト
- *※これらはツールの不具合ではなく、Web全体の安全を守るための「正しいセキュリティ制限」によるものです。*

## 使い方

1. リポジトリをクローンまたはダウンロードします。
2. `index.html` をブラウザで開くだけで実行できます（サーバーの起動は不要です）。
